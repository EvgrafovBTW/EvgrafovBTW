### Pioneer — typed navigation для Flutter

GitHub: https://github.com/EvgrafovBTW/pioneer

Авторский open-source пакет навигации на базе Flutter Navigator 2.0, готовящийся к alpha-релизу.

- Маршруты представлены неизменяемыми типизированными объектами; публичный API навигации не принимает строковые пути.
- Недоверенные deep links преобразуются в типизированные маршруты на системной границе.
- Реализован простой полный сброс состояния навигации — сценарий, отсутствующий в `go_router` и потребовавшийся при развитии NL Store.
